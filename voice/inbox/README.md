# Voice inbox

Drop anything here, any time, in any form: favourite expressions, jokes, a voice-message
transcript, a screenshot, a story from the apiary or the Jobcenter. One file per drop,
name it however you like (e.g. `2026-11-25-virazy.md`).

At the start of each session Claude reads new files here, moves the useful bits into
`../volodymyr.md` (or `../../bible/`), and moves processed files to `processed/`.
