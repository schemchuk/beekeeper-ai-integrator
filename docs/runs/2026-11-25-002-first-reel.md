## Lessons

- Review reels in a real player (Parole), never in the VS Code preview: it drops AAC audio.
- postpilot's manual intake is hard to use: the command must be the video's caption, every
  step waits up to 5 min for the next poll, and a button press gives no visible feedback.
  Volodymyr asks postpilot to rework it: clear commands, a hint at every step, the shortest path.
